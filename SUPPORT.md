# Getting Support for Mozhi

Thank you for using Mozhi! Here are the best ways to get help, ask questions, and report issues.

---

## 1. Questions & General Discussions
For usage questions, general prompt engineering workflows, or ideas on how to use Mozhi:
- Start or join a thread in [GitHub Discussions](https://github.com/JeevaVenkidu/mozhi/discussions).
- Check the [README.md](README.md) for local model setup guides, permission explanations, and BYOK configuration instructions.

---

## 2. Bug Reports
If you encounter unexpected errors, UI glitches, or inference failures:
- Search existing [GitHub Issues](https://github.com/JeevaVenkidu/mozhi/issues) to see if the issue is already tracked.
- If not, open a new issue using our **Bug Report** template.
- If the issue involves an API or model error, attach the sanitized error report generated from Mozhi **Settings → Error logs → Copy Markdown**.

---

## 3. Feature Requests
Have an idea for a new prompt mode, website integration, or SLM model?
- Open a new issue using our **Feature Request** template.
- Clearly describe your problem and how the proposed change helps.

---

## 4. Security Vulnerabilities
If you suspect a security or privacy vulnerability:
- Please refer to [SECURITY.md](SECURITY.md) for instructions on confidential disclosure.
- **Do not open public GitHub issues for security vulnerabilities.**
